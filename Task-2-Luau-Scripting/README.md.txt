Roblox Game Developer Internship --- Task 2

Introduction to Luau Scripting

This project is part of my Roblox Game Developer Internship.

Task 2 focuses on the basics of Luau scripting in Roblox Studio,
including changing part colors, detecting player touches using events,
and creating a Kill Brick.

Task Objectives

- Change a block's color using a Luau script.
- Detect when a player touches a part using the Touched event.
- Create a Kill Brick that kills the player and allows Roblox to respawn them.
- Understand basic Luau concepts such as variables, functions, events, conditions, and script.Parent.

Concepts Learned

- Luau scripting basics
- Variables
- script.Parent
- Functions
- Events
- Touched event
- :Connect()
- FindFirstChild()
- if conditions
- Humanoid
- Player death and respawning
- Basic server-side scripting
